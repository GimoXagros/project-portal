나리키리 던전3 v1.2는 B3TJ 일본어 원본용 한국어화 누적 패치의 공개 정식 릴리스입니다. 짜알님의 기존 한국어화 1.1을 허가받아 계승한 후속 작업입니다. 이번 릴리스는 원문 대조와 화면 확인 결과를 반영하지만 전편 완주, 모든 분기, 모든 기기의 무오류를 보증하지 않습니다.

어떤 범위를 보완했나

v1.1a 이후 대사 위치 972곳의 내용이 달라졌다고 공개 릴리스는 기록합니다. 이 중 새로운 위치 960곳과 기존 위치 재수정 12곳이 포함되며, 앞선 v1.1a에서 기록한 수정 위치도 누적으로 유지됩니다. 대사 수는 고유 문장 수와 같지 않다고 릴리스가 명시합니다. 표현·고유명사·장소 표기, 아이템과 몬스터 도감 속성을 검토했고, 불일치 후보 250개를 원문과 확인하여 19개 레코드를 보완한 마지막 용어 교정도 반영했습니다.

검증 범위와 한계

2026-09-23 15:05:52 UTC에 공개된 v1.2 릴리스는 mGBA와 VBA-Next에서 신규 게임 첫 저장, 별도 실행의 저장 재불러오기, 메뉴와 아이템 설명을 확인했다고 보고합니다. 각 코어에서 네 화면을 검토하고 첫 전투 경로 일부를 조작했으며, mGBA에서는 타이틀과 스탭롤 화면도 확인했습니다. 동일 입력 경로의 v1.1a와 비교한 장소 대사 변경 예도 기록되어 있습니다.

이는 제한된 PC 코어 확인입니다. 수정된 모든 장면을 직접 확인하거나, 자연 진행으로 모든 분기·전투·이벤트를 완료하거나, 모든 기기·에뮬레이터 조합을 검증했다는 뜻은 아닙니다. 저장 호환성도 모든 기존 세이브에 대해 보장되지 않습니다.

적용 안내와 기여자

포털의 나리키리 던전3 웹 패처에서 v1.2를 선택해 수정하지 않은 일본판 B3TJ 원본에 적용합니다. 기존 한국어화 ROM에 다시 적용하지 마세요. 결과와 기존 저장은 별도로 백업하고, 해당 버전의 주의사항을 따르세요. 이 글은 ROM이나 BPS 직접 다운로드를 제공하지 않습니다.

기존 한국어화 1.1은 짜알님, 후속 수정은 Xagros, 달무리 소형 글꼴은 RanolP와 기여자가 맡았습니다. 원작 게임과 프로젝트 로고 권리는 별도입니다. 자세한 내용은 CREDITS, v1.2 릴리스 노트와 v1.1a 원문 대조 기록을 참고하세요.

근거: v1.2 릴리스, v1.1a 이전 프리릴리스.
