# [개발노트] 나리키리 던전2 — v1.0 공개와 검증 범위

나리키리 던전2 v1.0은 AN9J 일본판 원본에 적용하는 한국어화 패치의 공개 정식판입니다. FFR 팀의 기존 한국어 번역을 바탕으로 Xagros가 후속 수정과 적용 패키지를 정리했습니다. 릴리스에 기록된 빌드·PC 검사와 완주·실기 검증은 별개이며, v1.0 안내도 전체 자연 진행과 모든 분기 검증이 끝났다고 말하지 않습니다.

## 이번 버전에서 정리한 내용

릴리스는 한국어 타이틀 로고의 숫자 2와 ® 표기, 엔딩 스탭롤 ASCII 글꼴, FFR/XAGROS 번역 크레딧과 감사 문구, 부팅 안내와 장소 이름을 수정 범위로 기록합니다. 아이템 156개와 몬스터 설명 142개도 검토했습니다. 대사 원문 대조 기록에서는 본문 8,037개 고유 ID와 8,945개 바인딩, 이름/UI 1,227개를 다뤘고, 본문 60개 ID에 속한 98개 바인딩을 교정했다고 밝힙니다.

v1.0 결과물은 직전 최종 검증 후보와 같고 공개 v0.9d와는 바이트가 다릅니다. 따라서 이전 프리릴리스의 결과를 현재 배포물의 검증으로 소급해 설명하지 않습니다.

## 공개된 검증과 남은 항목

2026-09-23 15:40:36 UTC에 v1.0 정식 릴리스가 공개됐습니다. 릴리스 기록에는 전체 체인 A/B 재빌드 일치, 실데이터 검사 166/166, 공개 CI 43/43, 타이틀/크레딧 6/6, 일본어 적용 7/7과 적용기 검사 7개 통과가 적혀 있습니다. PC mGBA에서 혼합 이름 신규 게임의 8 KiB 저장, 두 차례 재시작, 기존 저장과 중단 저장 복귀도 기록되어 있습니다.

미완료도 명확히 남아 있습니다. 기본 이름 신규 저장의 자동 입력 경로는 튜토리얼 대사 시점에서 완료되지 않았으며, 정확한 최종 결과물 해시와 연계된 실기 새 게임·재시작·저장 복귀, 전체 자연 진행과 주요 분기, 두 기기 통신은 확인되지 않았습니다. 공개 다운로드 파일의 재적용 검증은 발행 후 수행한다고 릴리스가 안내합니다. 공개 허용은 미실행 항목의 통과 판정이 아닙니다.

## 적용 경로와 크레딧

패치는 [포털의 나리키리 던전2 웹 패처](https://gimoxagros.github.io/project-portal/#/project/gba-narikiri2-kor)에서 v1.0을 선택해 적용하도록 안내합니다. 해당 버전의 입력은 수정하지 않은 AN9J 일본어 원본입니다. 원본과 저장을 백업하고, 적용 결과와 실행 환경을 구분해 관리하세요. 블로그에서 ROM이나 BPS 파일을 직접 내려받는 링크는 제공하지 않습니다.

원작 게임 및 번역 자산의 권리는 각 권리자에게 있습니다. 기존 번역과 패치 작업은 FFR 팀, 후속 패치·수정과 검증은 Xagros, 달무리 비트맵 글꼴은 RanolP와 기여자에게 각각 귀속됩니다. 세부 권리 고지는 [CREDITS](https://github.com/GimoXagros/gba-narikiri2-kor/blob/v1.0/CREDITS.md), [RIGHTS](https://github.com/GimoXagros/gba-narikiri2-kor/blob/v1.0/RIGHTS.md), [검증 기록](https://github.com/GimoXagros/gba-narikiri2-kor/blob/v1.0/verification/v1.0.json)에서 확인할 수 있습니다.
