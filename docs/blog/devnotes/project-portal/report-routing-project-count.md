# [개발노트] Project Portal — 프로젝트 수와 제보 경로 정리

2026년 9월 포털 갱신에서 프로젝트 수 표시와 GitHub 제보 경로를 정리했습니다. 당시 저장소에 등록된 프로젝트는 6개였지만, 홈의 배지가 다운로드 가능한 항목만 세어 5개로 보이는 문제가 있었습니다. 이 글은 공개 PR에서 확인되는 구현과 검증 범위를 기록하며, 현재 웹사이트의 기능 상태는 실제 배포를 확인한 뒤 게시해야 합니다.

## 프로젝트 수 계산

AI Work Skills는 저장소 설치 방식으로 제공되어 일반 다운로드 자산이 없습니다. 다운로드 가능 여부로 프로젝트 수를 계산하면 이 항목이 빠져 목록과 배지 수가 달라질 수 있었습니다. PR #18은 배지 값을 등록된 프로젝트 목록에서 계산하도록 고치고 사이트 소개, 공지, 공유 설명, FAQ와 문서를 6개 프로젝트 현황에 맞췄습니다.

## 제보 전달과 처리 현황

PR #16은 홈과 프로젝트 상세에서 제보·사용 후기를 작성해 GitHub 이슈 작성 화면으로 넘기는 UI와 공개 이슈 처리 현황 조회를 추가했습니다. 양식 이동만으로 접수가 완료되는 것은 아니며 GitHub 로그인 후 사용자가 최종 등록해야 합니다. 이슈 조회는 PR을 제외하고 상태를 분류하며, 최근 100개 조회 범위가 전체가 아닐 수 있다는 안내와 조회 실패 시 재시도·원본 링크를 제공합니다.

처음에는 이슈 기능이 꺼진 GameYob·GBARunner3·NitroSwan 제보를 포털 저장소에 모아 프로젝트 표식으로 구분했습니다. PR #17에서 세 저장소의 GitHub Issues를 활성화한 뒤 임시 전달 대상을 제거하고, 프로젝트별 이슈 작성과 현황 조회를 각 저장소에 직접 연결했습니다. 현재 접수 경로는 프로젝트별 GitHub Issues 설정을 따릅니다.

## 공개 검증과 한계

PR #16은 자동 검사 61개, 정적 데이터와 6개 프로젝트 릴리스 검증, 빌드 및 Edge 데스크톱·모바일 상호작용 검사를 기록합니다. PR #17은 세 저장소의 `has_issues=true` 확인과 직접 연결·공개 이슈 API 조회를 기록합니다. PR #18은 데이터 검사, 61개 테스트, 릴리스 원격 검증, lint/build와 PC·모바일 화면 검사를 기록합니다. QA 과정에서 실제 이슈를 등록하지 않았다는 점도 공개 PR에 명시되어 있습니다.

저장소는 2026-09-19에 아이콘·대표 이미지 등 보관소 브랜딩 자산을 추가했습니다. 이 브랜딩 변경은 프로젝트 수나 제보 동작과는 별개의 UI 정리입니다. 공개 사이트의 현재 배포 상태는 [프로젝트 포털](https://gimoxagros.github.io/project-portal/)에서 확인할 수 있습니다.
