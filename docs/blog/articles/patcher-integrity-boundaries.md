# [기술자료] 웹 패처의 세 가지 검증 — 파일이 맞는 것과 게임이 맞는 것은 다릅니다

웹 패처에서 원본 파일을 고르고 패치 적용이 끝났다고 해서, 모든 종류의 검증을 통과했다는 뜻은 아닙니다. Project Portal의 공개 패처 코드는 입력 원본, BPS 패치, 생성 결과를 각각 확인하고, 성공했을 때만 결과 파일을 내려받도록 구성되어 있습니다. 이 글은 그 검증 단계가 각각 무엇을 확인하고 무엇까지 보증하지는 않는지 구분합니다.

## 입력·패치·결과는 서로 다른 대상입니다

파일 크기는 빠른 구조 점검에 유용하고 SHA-256은 특정 바이트열을 등록된 지문과 비교하는 데 유용합니다. 하지만 세 파일은 각각 다른 기준을 가지므로 한 해시를 다른 파일의 해시와 비교할 수 없습니다.

| 대상 | 패처가 확인하는 기준 | 이 확인이 말해 주는 것 |
| --- | --- | --- |
| 사용자가 고른 원본 ROM | 선택한 패치 버전에 등록된 입력 크기·해시 | 선택한 버전이 기대하는 입력과 일치하는지 |
| BPS 패치 | 등록 자산의 크기·해시, BPS 내부 원본·결과 CRC32 검증 | 내려받은 패치가 등록 자산과 일치하고, 패치 엔진의 내부 무결성 검사를 통과하는지 |
| 패치 결과 | 결과 바이트의 크기·해시 | 생성된 결과가 해당 버전의 등록 결과와 일치하는지 |

원본 체크섬이 맞으면 파일 내용이 해당 버전이 요구하는 입력과 일치한다는 근거가 됩니다. 패치 자산 해시는 서버에 등록된 패치 파일과 받은 바이트가 같은지 비교합니다. BPS 자체에도 원본·결과 CRC32 필드가 있으며 적용기는 이 체크섬을 검증합니다. 결과 해시는 계산된 출력이 그 버전에서 예상한 결과와 동일한지 확인합니다. 각 단계가 서로 다른 질문에 답하는 셈입니다.

## 결과가 생기는 순서도 중요합니다

브라우저 패처는 검증 전 파일을 다운로드 가능한 결과로 노출하지 않습니다. 먼저 입력을 읽고, 선택한 버전의 패치 정보를 가져와 패치를 적용한 뒤 결과를 검증합니다. 검증 성공 후 결과 Blob 링크를 만듭니다. 버전을 바꾸면 이전 원본·결과를 더 이상 현재 선택의 결과로 취급하지 않도록 정리하고, 비동기 작업에는 작업 식별자를 붙여 오래 걸린 이전 작업이 늦게 끝나더라도 최신 선택을 덮어쓰지 않게 합니다.

따라서 오류가 났을 때는 “패치가 잘못됐다”고 바로 결론 내리기보다 선택한 버전, 원본 파일, 적용 중에 표시된 검사 결과를 분리해 봐야 합니다. 버전을 바꾼 뒤 옛 결과가 그대로 남아 있을 것이라고 가정해서도 안 됩니다. 실제 적용은 프로젝트 상세 페이지의 버전 선택형 웹 패처에서 진행합니다.

## 자동 검사는 무엇을 재현했나

공개 테스트에는 짧은 합성 바이트 배열에 BPS를 적용해 기대 출력이 나오는지 확인하고, 잘못된 원본 CRC32가 거부되는지 확인하는 사례가 있습니다. BPS 헤더의 원본·대상 크기와 몇몇 배포 패치 간 바이트 동일성도 검사 대상으로 기록되어 있습니다. 이 검사는 패치 계산 경로와 검증 조건이 코드대로 동작하는지 확인하는 소프트웨어 검사입니다.

여기서 말하는 합성 입력은 실제 상용 게임 ROM이 아닙니다. 이번 글의 근거는 소스 코드와 공개 테스트이며, 실제 ROM을 새로 제공받아 적용하거나 게임을 플레이해 검사한 결과를 뜻하지 않습니다. 공개 프로젝트에 기록된 개별 ROM 검증도 해당 프로젝트가 기록한 범위로만 해석해야 합니다.

## 해시가 보증하지 않는 것

SHA-256 일치는 두 바이트열의 지문이 같다는 비교 결과입니다. 그 자체만으로 파일의 법적 출처, 제작자 신원, 악성 여부, 패치 품질, 특정 콘솔에서의 실행 가능성, 게임 전체 완료 가능성을 인증하지 않습니다. 같은 이유로 입력 크기나 BPS 내부 체크섬이 맞는다는 사실도 실제 기기의 저장·화면·음향 동작을 대신 검증하지 않습니다.

사용할 때는 합법적으로 보유한 지원 원본을 준비하고, 화면에서 선택한 패치 버전과 원본 검증 결과를 확인한 뒤 적용하세요. 저장 결과는 원본과 분리해 보관하고, 결과 검증이 실패하면 억지로 우회하지 말고 선택한 원본·버전 정보를 확인해 제보해 주세요. ROM·세이브·BIOS 파일은 제보에 첨부하지 마세요.
