# 기존 게시글 수정 초안 — 나리키리 던전2·3 웹 패처 사용 방법과 오류 확인

- 대상: [post /3](https://gimoxagros.tistory.com/3)
- 처리: `update` 제안. 본문 전체를 대체하지 않고, 기존 두 상세 페이지 링크와 첫 적용 안내 다음에 최신 버전 단락을 삽입합니다.
- 보존: 2026-09-19 당시 나리키리 던전2 v0.9d 안내는 날짜가 명시된 과거 기록이므로 삭제하거나 현재 안내로 바꾸지 않습니다. 기존 절차, 오류 확인, 제보 방법, 크레딧도 보존합니다.
- 원문 보존: Sol이 관리자 편집기 원문 전체와 글 메타데이터를 확인하고 편집기 HTML을 gitignore 적용 로컬 QA 백업으로 보존했습니다. 해당 원문이나 백업 위치는 이 공개 원고 폴더에 넣지 않았습니다. 아래 결과물은 삽입 조각과 대조표이며 글을 자동 덮어쓰지 않습니다.

## 추가할 위치

서문과 두 프로젝트 상세 페이지 링크 뒤, 기존 `적용 전 준비` 앞에 아래 내용을 넣습니다. 기존의 `2026-09-19 포털 기준 ... v0.9d` 문장은 당시 정보로 유지하고, 최신 버전 단락이 현재 적용 안내임을 분명히 표시합니다.

## 티스토리 HTML 삽입 조각

HTML 편집기에서 아래 조각만 추가합니다. ROM·BPS 파일 다운로드 링크를 만들지 않습니다.

```html
<hr />
<h2 data-ke-size="size26">최신 공개 버전 (2026-09-24 KST 기준)</h2>
<p data-ke-size="size16">나리키리 던전2 v1.0과 나리키리 던전3 v1.2가 정식 릴리스되었습니다. 각각의 패치는 해당 게임 상세 페이지의 웹 패처에서 버전을 선택해 적용하세요.</p>
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li><a href="https://gimoxagros.github.io/project-portal/#/project/gba-narikiri2-kor">나리키리 던전2 웹 패처</a>: 수정하지 않은 AN9J 일본어 원본(8,388,608 bytes)이 필요합니다.</li>
<li><a href="https://gimoxagros.github.io/project-portal/#/project/gba-narikiri3-kor">나리키리 던전3 웹 패처</a>: 수정하지 않은 B3TJ 일본어 원본(16,777,216 bytes)이 필요합니다.</li>
</ul>
<p data-ke-size="size16">두 게임의 입력 원본과 패치는 서로 호환되지 않습니다. 기존 한국어화 ROM에 다시 적용하지 말고, 버전 선택 후 웹 패처가 표시하는 입력 파일 검증과 주의사항을 확인하세요. 포털에 새 정식 버전이 반영된 것을 확인한 뒤 적용할 수 있습니다.</p>
<p data-ke-size="size16">기존 본문에 있는 2026-09-19 기준 v0.9d 문장은 당시 공개판에 대한 기록입니다. 현재 버전 안내는 위 날짜 표시 단락을 기준으로 확인해 주세요.</p>
```

## 수정 대조표

| 구간 | 기존 내용 | 반영 제안 | 보존·근거 |
| --- | --- | --- | --- |
| 도입부 뒤 최신 정보 | 웹 패처에서 버전을 고르라는 일반 안내 | ND2 v1.0·ND3 v1.2 정식 공개 날짜와 각각의 실제 웹 패처 페이지 추가 | 기존 도입부와 링크 보존. 공개 릴리스의 tag·published_at 확인 |
| 입력 조건 | 게임별 원본이 다르다는 일반 설명 | AN9J 원본 8,388,608 bytes / B3TJ 원본 16,777,216 bytes를 최신 릴리스와 함께 표시 | 각 공개 릴리스 조건에 근거. ROM 제공·다운로드 금지 |
| 2026-09-19 v0.9d 문장 | ND2 v0.9d를 그날 기준 현재판이라고 안내 | 문구 삭제·치환 없이 역사적 시점 표기를 유지하고 현재 안내와 구분 | 당시 내용 보존. 최신판인 것처럼 다시 읽히지 않도록 위 삽입문을 추가 |
| 적용 링크 | 기존 웹 패처·제보 링크 | 추가 행동 링크도 웹 패처만 사용 | 직접 패치 다운로드·ROM 첨부 없음 |

게시 전 Sol이 현재 포털에 두 버전이 실제 선택 가능한지 확인해야 합니다. 확인 전 상태는 `draft_ready`입니다.
