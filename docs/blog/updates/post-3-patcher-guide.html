최신 공개 버전 (2026-09-24 KST 기준)

나리키리 던전2 v1.0과 나리키리 던전3 v1.2가 정식 릴리스되었습니다. 각각의 패치는 해당 게임 상세 페이지의 웹 패처에서 버전을 선택해 적용하세요.

  • 나리키리 던전2 웹 패처: 수정하지 않은 AN9J 일본어 원본(8,388,608 bytes)이 필요합니다.
  • 나리키리 던전3 웹 패처: 수정하지 않은 B3TJ 일본어 원본(16,777,216 bytes)이 필요합니다.

두 게임의 입력 원본과 패치는 서로 호환되지 않습니다. 기존 한국어화 ROM에 다시 적용하지 말고, 버전 선택 후 웹 패처가 표시하는 입력 파일 검증과 주의사항을 확인하세요. 포털에 새 정식 버전이 반영된 것을 확인한 뒤 적용할 수 있습니다.
